# NeerAI – Groundwater Prediction and Awareness System

NeerAI is a student project focused on groundwater level prediction and awareness using historical data from the Gandak River Basin.

## Features
- District-wise groundwater level prediction using Facebook Prophet
- Interactive chatbot-based interface (Flask)
- Historical trend analysis and visualizations
- Static water conservation tips for awareness

## Tech Stack
- Python
- Facebook Prophet
- Flask
- SARIMA (analysis)
- Matplotlib

## Dataset
- BitByte Groundwater Dataset
- Gandak River Basin (26 years of data)

## Note
This project was developed as a collaborative effort. My contribution focused on the prediction module and application integration.
